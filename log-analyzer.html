主機記錄檔資安檢視工具

把 Windows 事件記錄檔或 Linux 系統記錄檔拖進來，自動整理成看得懂的資安檢查報表。

🔒 檔案只在這台電腦的瀏覽器內分析，不會上傳到任何地方，離線也能使用
把記錄檔拖曳到這裡，或點一下選擇檔案
可一次放多個檔案（Windows 與 Linux 可混合）。支援：.evtx、wevtutil 匯出的 XML、事件檢視器匯出的 CSV、Linux auth.log / secure / messages / syslog / audit.log / journalctl 輸出（.gz 也可以）

第一次使用？照著 3 個步驟做

① 從主機取出記錄檔依下方教學，把主機的「記錄檔」另存出來（不會影響主機運作）。
② 拖進上方的虛線框可以一次放很多個檔案。檔案只在這台電腦上分析，不會傳到網路上。
③ 看報表先看最上面的紅/黃/綠結論，再看「異常發現」與「定檢檢核表」。

要放哪些檔案

需要程度記錄名稱匯出後的檔名用來檢查什麼
一定要安全性 (Security)Security.evtx登入成功/失敗、來源 IP、帳號與群組異動、記錄被清除

有更好應用程式 (Application)Application.evtx軟體安裝/移除、程式當機
有更好Windows Defender、PowerShell、遠端桌面、工作排程器（用方法 B 一次匯出）病毒偵測、可疑指令、遠端連線來源、排程異動

方法 A：用滑鼠操作（不熟指令的人用這個）

  1. 在要檢查的那台主機上，按鍵盤 Win + R，輸入 eventvwr.msc 後按 Enter，開啟「事件檢視器」。
  2. 左邊點開「Windows 記錄」。
  3. 在「安全性」上按滑鼠右鍵 →「另存所有事件為…」。
  4. 存檔類型維持「事件檔案 (*.evtx)」，檔名取 Security，存到桌面。若跳出「顯示資訊」視窗，選「不顯示資訊」即可。
  5. 對「系統」、「應用程式」重複步驟 3–4。
  6. 把存好的 .evtx 檔案複製到放這個網頁的電腦，拖進上方虛線框。

看不到「安全性」的內容或無法另存？代表目前帳號不是系統管理員，請改用管理員帳號登入，或對事件檢視器按右鍵「以系統管理員身分執行」。

方法 B：用指令一次匯出全部（較快、內容最完整）

  1. 按「開始」，輸入 cmd，在「命令提示字元」上按右鍵 →「以系統管理員身分執行」。
  2. 按下方「複製指令」，到黑色視窗按滑鼠右鍵貼上，再按 Enter。
  3. 完成後檔案會在 C:\logs 資料夾，把裡面的檔案全部拖進上方虛線框。
mkdir C:\logs
wevtutil epl Security    C:\logs\Security.evtx /ow:true
wevtutil epl System      C:\logs\System.evtx /ow:true
wevtutil epl Application C:\logs\Application.evtx /ow:true
wevtutil epl "Microsoft-Windows-Windows Defender/Operational" C:\logs\Defender.evtx /ow:true
wevtutil epl "Microsoft-Windows-PowerShell/Operational" C:\logs\PowerShell.evtx /ow:true
wevtutil epl "Microsoft-Windows-TerminalServices-LocalSessionManager/Operational" C:\logs\RDP-Session.evtx /ow:true
wevtutil epl "Microsoft-Windows-TerminalServices-RemoteConnectionManager/Operational" C:\logs\RDP-Connect.evtx /ow:true
wevtutil epl "Microsoft-Windows-TaskScheduler/Operational" C:\logs\TaskScheduler.evtx /ow:true
explorer C:\logs

出現「存取被拒 (Access is denied)」＝沒有用系統管理員身分執行。某幾行顯示找不到記錄檔沒關係，代表那台主機沒有該功能，其餘照常可用。

同名但後面多了 .1、.2.gz 的是較舊的記錄（例如 auth.log.1、auth.log.2.gz），請一起放進來，才看得到完整期間。.gz 壓縮檔不用解壓縮，直接拖進來即可。

取出檔案的步驟

  1. 用 SSH 登入主機（或在主機前開啟終端機）。
  2. 按「複製指令」貼上執行，會把記錄複製到家目錄的 logs 資料夾（需要輸入 sudo 密碼）。
  3. 用 WinSCP、FileZilla 或 scp 把 logs 資料夾下載到放這個網頁的電腦。
  4. 把資料夾裡的檔案全部選起來，拖進上方虛線框。
mkdir -p ~/logs
sudo cp /var/log/auth.log* /var/log/secure* /var/log/syslog* /var/log/messages* /var/log/audit/audit.log* ~/logs/ 2>/dev/null
sudo chown -R "$USER" ~/logs
ls -lh ~/logs

找不到上面那些檔案？

較新的系統可能只用 journal 保存記錄。請改執行下面這行，會產生一個 journal.log，把它拖進來即可。

sudo journalctl -o short-iso --since "-180 days" > ~/journal.log
  1. 先看「總覽」最上面的結論框：紅色＝有高風險異常要盡快處理；黃色＝有事項需要確認；綠色＝沒有發現明顯異常。
  2. 再看「異常發現」：每一項點開都有「這代表什麼」（白話解釋）、「證據」（哪個帳號、哪個 IP、什麼時間）和「建議處置」（該怎麼做）。
  3. 「定檢檢核表」可直接當作檢查紀錄：逐項顯示 異常／需注意／有紀錄請確認／未發現異常／無資料。「無資料」表示還缺某個記錄檔，說明欄會寫需要哪一個。
  4. 「登入分析」的圖表：橘色代表登入失敗。橘色突然暴增、或集中在半夜假日，通常就是有人在猜密碼。IP 旁標示「外網」表示來自網際網路。
  5. 需要留存或回報時，按右上角「列印 / 存成 PDF」。

本工具是依據常見的攻擊特徵做自動判讀，目的是幫忙「找出值得注意的地方」。標示為異常不一定代表已被入侵，沒有標示也不保證絕對安全；有疑慮請洽資安人員。

常見問題

  • 檔案很大可以嗎？可以，幾百 MB 也能分析，只是需要等一下。
  • 可以放多台主機的檔案嗎？可以，但建議一次分析一台，報表比較好讀。換下一台前請按「清除並重新開始」。
  • 哪些檔案不能用？網站存取記錄 (IIS / Apache / Nginx)、資料庫或應用程式自己的 log、壓縮成 .zip / .tar 的檔案（請先解壓縮）。
  • 檔案會外流嗎？不會。這是一個離線網頁，所有分析都在你的瀏覽器內完成，關掉網頁資料就消失。
